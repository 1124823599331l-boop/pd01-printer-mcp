# Attribution

This project implements command framing and BLE GATT behavior for PD01-compatible thermal printers based on public reverse-engineering references.

Primary reference:

- `rhnvrm/catprinter` — https://github.com/rhnvrm/catprinter — MIT License

The upstream project documents the proprietary 0x5178 packet format, 384-dot paper width, CRC8 checksum, and AE30/AE01 GATT interface.
